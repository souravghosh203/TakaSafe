# Deployment guide

Project-specific notes for building, deploying, and recovering TakaSafe. These pages record repository evidence; they do not certify that a hosting environment is active.

> [!IMPORTANT]
> **Deployment status needs confirmation.** A GitHub Pages workflow and a Surge script are present. The repository does not establish which one is the live release path, or where the API services run.

## Read the guide

| Page | What it covers |
|---|---|
| [Environments](environments.md) | Runtime modes, environment variables, secrets, and service boundaries |
| [Build](build.md) | Prerequisites, install commands, build output, and scripts |
| [Deployment](deployment.md) | Declared deployment paths, server modes, checks, and operational gaps |
| [Rollback](rollback.md) | Existing recovery support and what must be confirmed manually |
| [Release checklist](release-checklist.md) | A practical checklist to work through before and after a release |

### Evidence labels

- **Verified in repository** means the detail is present in checked-in source or configuration.
- **Needs confirmation** means repository files alone cannot establish the live setup or operational behavior.
